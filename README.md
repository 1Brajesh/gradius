# Starwake (working title)

An original side-scrolling space shooter for the browser. See [PLAN.md](PLAN.md).

## Play it locally
```sh
cd ~/Documents/Coding/gradius/public
python3 -m http.server 8000
```
Then open http://localhost:8000 in Safari or Chrome.

(The game uses JavaScript modules, which browsers won't load straight from a file, so it needs this little local server.)

## Controls
Move: arrow keys / WASD · Fire: Z / Space · Take power-up: X / Shift · Pause: P / Esc · Sound on/off: M

**Phones and tablets:** hold the device sideways. Drag anywhere to steer (the ship moves by how far your thumb moves, so your finger never covers it). The gun fires by itself. Tap POWER to take a power-up; pause and sound buttons sit top left.

**Install as an app:** on iPhone/iPad, Safari → Share → *Add to Home Screen*. On Android, Chrome → menu → *Install app*. It then opens full screen and works offline.

Live at https://starwake.brajesh.com
